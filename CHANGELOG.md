# Changelog

All notable changes to `laravel-form-builder` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-03

### Added
- Initial public release.
- 21 field types including text, choice, media, and pro types.
- Drag-and-drop Admin UI built with Alpine.js and SortableJS.
- Submissions management system with export capabilities (CSV, Excel, PDF).
- Dynamic conditional logic engine for field visibility.
- Comprehensive PHPUnit test suite.
- Polished, responsive Bootstrap 5 integration for rendering forms.
- Webhook and Email notification integrations.
