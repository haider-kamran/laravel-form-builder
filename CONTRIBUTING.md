# Contributing to Laravel Form Builder

First of all, thanks for taking the time to contribute! 🎉

The following is a set of guidelines for contributing to this package. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## How Can I Contribute?

### Reporting Bugs

- Ensure the bug was not already reported by searching on GitHub under Issues.
- If you're unable to find an open issue addressing the problem, open a new one. Be sure to include a title and clear description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- Open a new issue with a clear title and description.
- Explain why this enhancement would be useful to most users.
- Provide examples of how the enhancement would look or be used.

### Pull Requests

- **Branching**: Create your feature branches from the `main` branch.
- **Coding Style**: Please follow PSR-12 coding standards.
- **Testing**: Add PHPUnit tests for any new features or bug fixes.
- **Documentation**: If you change functionality, update the `README.md` accordingly.

## Setup for Development

1. Fork the repo and clone it locally.
2. Run `composer install` to install dependencies.
3. Run `vendor/bin/phpunit` to ensure all tests pass before making changes.

Thank you for contributing!
